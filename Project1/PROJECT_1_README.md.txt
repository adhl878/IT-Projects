# Project 1: System Information Collector

## Description
Python script that automatically collects and reports system information including OS, CPU cores, and RAM.

## Purpose
Demonstrates ability to automate IT support diagnostics and system monitoring.

## How it Works
- Collects OS information (Windows, Linux, etc)
- Reports CPU cores and logical processors
- Displays RAM total, used, and available
- Shows disk usage statistics
- Displays network configuration
- Generates timestamped reports

## Requirements
- Python 3.6+
- psutil library (`pip install psutil`)
