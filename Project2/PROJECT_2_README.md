# Project 2: Virtual IT Lab Infrastructure

## Description
Built virtual network environment with 2 VMs using VirtualBox.

## Infrastructure
- VM1: Windows 10 (Client/Workstation)
  - IP: 192.168.1.100
  
- VM2: Ubuntu Linux (Server)
  - IP: 192.168.1.101

## Network Configuration

- Static IP assignment
- Both VMs can ping each other (connectivity verified)
