# Project 3: IT Maintenance Automation Script

## Description
Batch script automating common IT support tasks.

## Features
1. System Information - Displays OS, CPU, RAM details
2. Clear Temp Files - Removes temporary files
3. Flush DNS Cache - Clears DNS cache for network fixes
4. Check Network - Shows detailed network configuration
5. Exit

## Purpose
Automates repetitive IT support tasks to save time and reduce manual work.

## Skills Demonstrated
- Batch scripting (Windows automation)
- IT support task automation
- Command-line programming
- Menu-driven interface design
- System administration scripting

## How It Works
- Menu-driven interface
- User selects option
- Script executes corresponding task
- Returns to menu or exits

## Usage
Run as Administrator:
```
IT_Maintenance_Script.bat
```
